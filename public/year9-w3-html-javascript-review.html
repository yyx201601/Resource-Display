HTML + JavaScript Review

Practice: finding an id and changing textContent.

Remember:
Find the correct id in the HTML → use that same name in JavaScript → change the text with .textContent.

1A. Teacher Example

Change Bonjour! to Ciao!.
<h1 id="greeting">Namaste!</h1>
<h2 id="hello">Bonjour!</h2>

<button id="update">
  Update
</button>

<script>
function clickAction() {
  hello.textContent = 'Ciao!';
};

update.onclick = clickAction;
</script>

Namaste!

Bonjour!
